## What's broken

### Knowledge layer: 0/17 SQL entries execute against staging RDS

After re-running Gemini conversion with `max_output_tokens=32000` to fix the 5 `needs_review` entries, then validating with `06_validate_pipeline.py --execute-sql`:

- **0 of 17** `sql_equivalent` entries execute without error.
- This includes the 13 that previously "succeeded" in step 05 but were never executed against staging.

Breakdown:

| Failure class | Count | Cause |
|---|---|---|
| Validator wrap bug | 7 | `SELECT * FROM (<sql>) AS _v LIMIT 1` wrap breaks when inner SQL has trailing `;` or `-- comment`. Inner SQL may be valid; needs unwrapped re-test. |
| Multi-statement `SET @var; SELECT ...` | 3 | Gemini emitted multi-statement SQL that can't be wrapped. `team-performance`, `case-analytics`, `cms-payments`. |
| Other syntax errors | 7 | Real bugs. `JSON_OBJECT()` misuse, table casing (`` `Case` `` vs `case`), `${var}` template-literal leakage, stubbed helper functions. |

### Where this matters / doesn't matter

- **Known-report path** (V10's primary): does NOT call `get_idre_business_logic`. Calls IDRE's actual API directly. **All 15/15 Day-9 PASSes are unaffected.**
- **Derived-query path** (V10's secondary): LLM calls `get_idre_business_logic` as a starting point. With current broken SQL:
  - `verify_sql_executes` catches syntax errors at runtime → extra round-trips
  - Stubbed/inferred logic produces SQL that parses but returns wrong numbers → silent failures
  - This is the failure mode that motivated V10 in the first place

### What was stated optimistically and shouldn't have been

> "Concretely: `get_idre_business_logic('due-dates')`, `('cms-payments')`, `('dashboard-stats')`, `('auditing/daily-funds')`, `('case-analytics')` now all return real Prisma + JS + SQL triples to the LLM during derived-query generation."

This was overconfident. The fields ARE populated but the SQL doesn't execute. Should have validated with `--execute-sql` before declaring complete. Gemini's own notes ("inferred from function names", "logic could not be translated and is stubbed") were warning signs that got shipped past.
